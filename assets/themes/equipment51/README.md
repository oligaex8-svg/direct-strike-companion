# Registered equipment optics — local.51

Original native models/UVs/animation remain unchanged. `Build-Equipment51.cjs` derives an additional optical layer from the already rendered original Hyperion map, Armory screen, Pylon crystal and Leviathan vascular tissue. The catalog records exact source/result hashes and explicitly labels channel selection, blur, intensity and loop timing as authored presentation. This is not an exported engine emissive pass. It adds no invented buttons, frames, geometry, moving border lines or repeated props.

Each soft layer lives inside its original atlas element and inherits that element's one source animation transform. Half-resolution optical tiles reduce decoded memory while retaining exact grid registration. There is no independently moving duplicate of the machine. Source geometry remains the visual silhouette; glow cannot introduce a different pose or interfere with reading pixels.

Terran uses green instrument bloom, Protoss blue crystal bloom and Zerg a warm vascular sheen. Periods are 4.6/3.5 seconds for the two Terran displays, 6.4 seconds for the crystal and 4.2 seconds for tissue. Continuous native object animation and gentle ambient light continue; confirmed replay analysis increases the optical intensity. Pause, disconnection and error quiet the optics. `renderImportProgress()` supplies actual work state. Repeated refreshes never create a new clock. Failed requests do not invent work activity. Settings supplies a separate 12-second busy demonstration. This is not a one-shot scan movie.

`campaign-interiors.js::equipmentLayout()` now owns both Terran machine positions. The monitor sits 10px above the map against the lower utility casing. The secondary device is omitted when room is insufficient, followed by the assembly below its minimum height. Settings aligns both on a common base. Main content/control rectangles retain Default geometry. Native blur, modal scope, offscreen visibility, reduced motion and forced colours gate optical loops. The redundant Protoss/Zerg preview casing effects were removed because they crossed the model or produced stray strips; main UI frame art is unchanged.

Evidence: `verification/local51-equipment/report.json`, `confirmation.json`, `zerg-preview.json`, actual full UI screenshots and three actual UI GIF captures. Candidate source inspection also found static vent meshes and unsupported cryotube refraction/bridge volume material families. Those remain research-only in `campaign48/`; no partial substitute was shipped. No local.49 artwork returns.
